# Movie Recommendation System

A Machine Learning based movie recommendation system built using Python, Pandas, and Scikit-learn.

## Features

* Content-based recommendation
* Similar movie suggestions
* Data preprocessing and feature engineering
* Cosine similarity algorithm

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook
